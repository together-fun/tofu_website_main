# Together.fun — Landing Page

Source of the [together.fun](https://together.fun) landing page.
**Together.fun (TOFU)** is a gamified social trading platform built on Hyperliquid —
where trading, gaming and community merge into one entertainment layer.

> This repository contains the marketing site only. The trading app and backend are not part of this repo.

## Stack

- [Next.js 16](https://nextjs.org) (App Router) + React 19
- Tailwind CSS v4 + shadcn/ui
- framer-motion + Lenis smooth scroll
- Deployed on Cloudflare Workers

## Local development

```bash
pnpm install
pnpm dev        # http://localhost:3000
pnpm build      # production build
```

Requires Node.js 20+ and [pnpm](https://pnpm.io).
